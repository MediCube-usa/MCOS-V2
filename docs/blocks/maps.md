# Block spec — Maps & Routes (+ THE MAP CARD)

Status: map pinning console existed; MAP CARDS added 2026-08-19 (Joe: "one of the most
important parts — don't leave anything out").

The map card is the ONE shared card per machine that goes out to restocking, distribution,
setup and service. Canonical home: this page (`#map-cards`). Storage: `machine_locations`
(one row per machine) + refill videos/docs links on `machines`.

## Card contents (all editable on the card, spaces + links for everything)
- Machine name, ID, campus
- Address
- Google Maps pin link — "directions there on google"
- WALK-OUT location — the actual spot (building, floor, hallway, which door)
- Directions to the machine (from parking/entrance)
- Directions THROUGH the machine (open, load, close — what the refiller does)
- Fill times — what times it must be filled
- Time of access
- Follow-up date (calendar)
- Contact name + number, plus extra contacts/numbers
- Photos: machine / hallway / location (link spaces for each)
- Refilling videos link, documents link, refill notes
- Access notes (where the lockbox is — NEVER the code; the key code releases only after
  on-site verification, per the restocking flow)

A card counts COMPLETE when it has at least address + Google pin + walk-out location
(completion counter on the page). Restock tasks display a read-only summary and deep-link
here for edits — one card, no duplicates across departments.
