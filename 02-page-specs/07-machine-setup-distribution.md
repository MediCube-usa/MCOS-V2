# Page Spec: Machine Setup & Distribution

## Purpose

Pre-live machine lifecycle page.

Tracks machines from TCN order through shipping, logistics, delivery, placement, setup, initial stocking, and go-live approval.

## Lifecycle

- TCN order
- machine model/quantity selected
- order sheet and TCN contacts
- coil setup decisions
- credit card reader decisions
- key lock/fob decisions
- decals/branding decisions
- router/internet plan if applicable
- shipment/import paperwork
- port arrival
- Brendamour pickup
- warehouse/holding
- facility assignment
- delivery scheduling
- facility contact coordination
- placement location
- insurance/contracts attached
- machine delivered
- machine placed
- machine plugged in
- machine online
- template assigned
- initial stock loaded
- payment reader verified
- MCOS verifies machine live
- facility goes live

## Needed Records

- TCN contact info
- TCN order sheet
- machine order status
- machine serial/ID
- shipping/import details
- port details
- Brendamour logistics info
- delivery schedule
- facility contacts
- location address
- exact placement
- setup photos
- contracts/insurance
- assigned template
- assigned restocker
- initial stock plan
- go-live checklist
- invoices

## Agent Role

Setup Agent:

- suggested name: Derek
- tracks machine order/setup lifecycle
- coordinates next steps
- alerts Command Center when machines are blocked or ready

## Alerts

- shipment delayed
- missing paperwork
- delivery date missing
- facility contact missing
- placement not confirmed
- machine not online
- initial stock missing
- payment reader not verified
- go-live approval blocked

## Command Center Block

Shows:

- machines in setup
- blocked setup steps
- upcoming deliveries
- machines ready for live approval
- missing documents/invoices
